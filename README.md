JavaScript/HTML5 remake of the Famicom "Battle City" game
=====================================================

Added 2 players mode

Download the code and run BattleCity.html

Player 1 - W,A,S,D to move and E to shoot

Player 2 - Arrows to move and / to shoot

The code was written with TDD (Test-Driven Development) methodology.
